# 외부 에셋 출처

이 프로젝트가 직접 만들지 않고 받아온 것들의 목록입니다.
**전부 CC0(퍼블릭 도메인)이라 표기 의무는 없습니다.** 그래도 적어 두는 이유는,
"이건 어디서 왔지"라는 질문이 나중에 반드시 나오고, 그때 답이 없으면 지워야 하기 때문입니다.

소리·거미줄·혈흔·비네트 텍스처는 **코드로 생성**합니다. 받아온 것이 아닙니다.
(`AudioBuilder`, `DecayBuilder`, `TextureBuilder`)

## 모델 — Poly Haven (CC0)

받는 방법은 하나로 고정되어 있습니다:

```bash
python tools/get-model.py --list <이름>   # 크기·용량만 확인
python tools/get-model.py <이름> ...      # 실제로 받기
```

## 받은 모델을 그대로 쓰지 않는 이유

`ModelSkin`이 **재질을 새로 만들어 덮어씁니다.** 받아온 모델은 전부 대낮에 찍은
사진으로 칠해져 있어서, 그대로 넣으면 벽이 0.4배로 어두워진 방 안에서 혼자
번쩍입니다. 처음 넣은 서랍장이 정확히 그랬습니다 — 좋은 가구처럼 보이는 게 아니라,
**어두운 집 쪽이 실수처럼** 보였습니다.

`DecayBuilder`가 그 위에 낡음을 입힙니다. 기울이고, 문짝 하나를 떨어뜨리고,
구석에 거미줄을 칩니다. 전부 **놓인 위치에서 뽑은 시드**로 결정하므로 다시 지어도
같은 방이 같은 방식으로 썩습니다.

---

## 쓰지 않은 것

요청받았던 **디컴파일 저장소는 열지 않았습니다.** 상용 게임을 역컴파일한 코드를
참고하면 이 프로젝트가 원작 코드의 파생물이 됩니다. 게임 규칙은 저작권 대상이
아니므로 공개 자료를 바탕으로 전부 새로 구현했고, 원작의 이름·캐릭터 디자인·대사·
음성·모델·로고는 사용하지 않습니다.
