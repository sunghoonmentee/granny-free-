# 아가타의 집 — 작업 요약

> 원작 *Granny*(DVloper, 2017)의 **규칙**을 그대로 옮기고, 캐릭터·이야기·집·아트는
> 전부 새로 만든 1인칭 생존 호러. Unity 6000.5.8f1 / URP.
>
> 이 문서는 작업이 끊겼을 때 **여기부터 다시 읽으면 되는** 지점입니다.
> 마지막 갱신: R5-4 (집을 집답게) 진행 중.

---

## 1. 지금 상태 한 줄

플레이 가능한 Windows 실행 파일이 있고, 원작의 핵심 규칙이 전부 들어가 있으며,
집은 기획서 평면도대로 서 있고, **방에 가구와 잡동사니가 들어차 있습니다.**

**테스트: EditMode 80/80 · PlayMode 117/120 통과, 실패 0** (3개는 그래픽이 필요한 캡처 시나리오라 기본 스킵)

---

## 2. 실행 방법

| 무엇 | 어떻게 |
|---|---|
| 게임 하기 | 바탕화면 **`아가타의 집`** 바로가기, 또는 `Build/AgatasHouse/AgatasHouse.exe` |
| 전체 다시 짓기 | `./tools/unity.ps1 run -Method Granny.EditorTools.RebuildAll.Run` |
| 테스트 | `./tools/unity.ps1 test -Platform EditMode` / `-Platform PlayMode` |
| 실행 파일 굽기 | `./tools/unity.ps1 run -Method Granny.EditorTools.GameBuilder.BuildWindows` |
| **집 둘러보기 (사진)** | `./tools/unity.ps1 run -Method Granny.EditorTools.HouseTour.Run -WithGraphics` |
| 집 진단 | `./tools/unity.ps1 run -Method Granny.EditorTools.HouseDoctor.Run` |
| 아가타·가구 사진 | `./tools/unity.ps1 run -Method Granny.EditorTools.AgataPortrait.Run -WithGraphics` |
| 모델 치수 재기 | `./tools/unity.ps1 run -Method Granny.EditorTools.ModelReport.Parts` |
| 모델 받기 | `python tools/get-model.py --list <이름>` → `python tools/get-model.py <이름>` |
| 플레이 녹화 | `./tools/unity.ps1 test -Platform PlayMode -WithGraphics -Extra @('-runScenario','-testFilter','HearingScenarioCapture')` |

**빌더 실행 순서는 `RebuildAll` 하나에 고정되어 있습니다.** 순서를 직접 바꿔 돌리면
`HouseBuilder`가 지우고 다시 만드는 마커를 `GrannyBuilder`가 가리키게 되어 null이 생깁니다.

### 도구 셋이 핵심입니다

눈으로 봐야만 보이는 문제가 대부분이라, 보는 도구를 먼저 만들고 그걸로 고칩니다.

- **`HouseTour`** — 집 안 9곳 + 손에 든 물건 2장을, **집의 조명만으로, 눈높이에서** 찍습니다.
  카메라가 고정이라 두 번 찍어 나란히 놓으면 차이가 곧 변경사항입니다.
  (초상화 도구는 자기 조명을 들고 다녀서 재질 판단에는 못 씁니다 — 그걸로 맞춘 가구는
  한 방에선 카탈로그 같고 옆 방에선 바닥 구멍 같았습니다.)
- **`HouseDoctor`** — 도달 가능 범위 지도, 계단, 막힌 곳, **겹친 지오메트리**.
- **`ModelReport.Parts`** — 받은 모델의 각 부품 크기와 위치. 서랍장의 일곱 메시 중
  어느 것이 서랍인지는 이름으로 못 맞춥니다.

## 3. 끝난 것

### R1 — 고치기 ("쫓아온다")
- **청취 규칙**: `NoiseBus`가 좌표 + 층을 담아 **집 전체로** 발행. 반경 판정 폐기.
  깨짐 · 물건 충격 · 문 세게 닫기 · 도구질 · 덫 · 삐걱임 · 종만 통과.
  **걷기 · 문 여닫기 · 서랍은 통과하지 않습니다.**
- **한 손 원칙**: 벨트 5칸 제거, 손 하나만. (벨트 코드는 `backup/belt-inventory` 브랜치)
- 검증: 지하 스폰 → 2층 병 깨짐 → **실제로 29초 만에 도착**하는 3카메라 녹화

### R2 — 원작 규칙
| 단계 | 내용 |
|---|---|
| R2-1 | 삐걱이는 바닥(웅크리면 조용), 인계철선 종(하루 한 번) |
| R2-2 | 수색 실패 → **병목에 곰덫 설치**(최대 3개), 밟으면 20초간 속도 60% |
| R2-3 | **숨는 걸 봤는가** 규칙 — 봤으면 그 옷장을 정확히 열러 옴. 침대 밑 숨기 |
| R2-4 | 석궁 조립(부품 3개, 작업대), 기절 120/60/30/15초, **먼 곳 부활** |
| R2-5 | 소리 15종을 **코드로 합성**, 3D 오디오, 지팡이 소리로 위치 추적 |
| R2-6 | 날짜별 부상(시야 흔들림·핏자국, **속도는 안 깎음**), 점프스케어 |

### R3 — 집 다시 짓기
- 중앙 홀 + 네 모서리 방, 2층도 같은 벽선 위에
- **트인 현관 홀** — 2층 바닥에 구멍 + 사방 난간
- **차고 + 기어가는 통로** — 천장 1.2 m. 그녀는 1.9 m라 **걸을 면 자체가 생성되지 않음**

### R4 — 탈출과 퍼즐
- **배치 5종** (무작위 아님), 선택된 배치는 세이브에 기록
- **현관문 6단계**, 난이도가 떼어냄: 3 / 3 / 4 / 5 / 6
- **트럭 탈출** (차고) — 사슬·플러그·배터리·연료·열쇠 5개

### R5 — 아트
| 단계 | 내용 |
|---|---|
| R5-1 | 아가타가 캡슐에서 **관절 있는 인물**로. 굽은 등, 긴 팔, 발광하는 눈, 쇠끝 지팡이. `AgataPose`가 **에이전트의 실제 속도**에서 걸음 계산 |
| R5-2 | 벽·바닥·계단 텍스처 (ambientCG CC0). 틴트를 **생각보다 훨씬 많이** 내려야 함 — 대낮 사진이라 그대로 넣으면 불 꺼진 모델하우스가 됩니다 |
| R5-3 | 가구 모델 3개 + `DecayBuilder` — 기울이기, 부품 하나 떼기, 거미줄 |
| R5-4 | **집을 집답게** (아래) |

### R5-4 — 집을 집답게 (진행 중)

사진을 찍어 보고서야 보인 것들입니다. 테스트는 전부 통과하고 있었습니다.

1. **지붕이 없었습니다.** 다락 평면이 본채보다 작아서, 그 바깥 고리 아래 방들은
   **천장 없이 하늘이 보였습니다.** 2층 손님방에서 위를 보면 파란 대낮 하늘.
   → 고리를 다락 바닥 높이에서 막고, 카메라 clear를 **검정**으로 (하늘 아님).
2. **빛이 차가웠습니다.** 주변광 0.16의 푸른 회색이 모든 방을 균등하게 비춰서
   달빛 아래 공사장처럼 보였습니다. → 0.112의 따뜻한 색으로 **낮추고**, 빛은
   스물세 개의 전구에서 오게. 어둠은 벽이 아니라 빛 사이의 공간.
3. **벽이 기어다녔습니다.** 전구 스물세 개가 그림자 맵 하나를 나눠 쓰면서 생긴
   얼룩을 **더러운 벽지로 착각**하고 세 번이나 지나쳤습니다. → 아틀라스 4096,
   bias 상향, 그림자 거리 35 → 22 m.
4. **방이 비어 있었습니다.** → `ClutterBuilder`, 57개를 손으로 배치.
   문간·계단·트럭 자리를 피하고, **모델의 실측 크기**로 충돌 상자를 잡습니다
   (처음엔 2.27 m짜리 빅토리아 의자에 0.5 m 상자를 줬습니다).
5. **창문이 하나도 없었습니다.** 창 없는 집은 무서운 집이 아니라 벙커입니다.
   → **판자로 막은 창** 16개. 벽을 뚫지 않습니다 — 막혀 있고 까만 창은
   뒤에 뭐가 있든 똑같이 보이니까요.
6. **난간이 판자벽이었습니다.** 응접실에 가축 우리가 서 있는 것처럼 보였고,
   트인 홀을 만든 이유(난간에서 현관문이 보이는 것)를 그 판자가 막고 있었습니다.
   → 난간동자 + 손잡이 + 엄지기둥. 간격 0.22 m는 **에이전트 반경 0.3 m에 막힙니다.**
7. **문이 갈색 직사각형이었습니다.** → 양면 패널 4장 + 손잡이, 나무 텍스처.
   현관문은 널빤지 + 쇠 띠 + 고리.
8. **검은 면이 거울이었습니다.** URP 기본 smoothness 0.5 + 어두운 색 = 전구가
   주황색 얼룩으로 번졌습니다. 현관문에 불을 피워 놓은 것 같았습니다. → 0.1로.
9. **손에 든 물건이 안 보였습니다.** 한 손 규칙을 어디서나 강제하면서 어디에도
   보여주지 않았습니다. → `HandView` — 카메라 아래 오른쪽, 걸음에 맞춰 흔들림.
   **망치·펜치·병은 진짜 모델**입니다.
10. **카펫이 갈색 판지로 보였습니다.** 무늬를 코드로 그려 넣었는데도요.
   → **이방성 필터링.** 비스듬히 보는 면은 밉맵이 텍스처의 *평균색*을 돌려줍니다.
   무늬가 틀린 게 아니라 **화면까지 도달하지 않고 있었습니다.** 괘종시계가 2 m에선
   짙은 갈색이고 8 m에선 밝은 황갈색이던 것도 같은 이유였습니다.

### R5-5 — 까마귀와 금고

- **까마귀** — 횃대에 앉아 있다가 3.6 m 안에 들어오면 웁니다. 55초 쉬고 다시 봅니다.
  **웅크려도 소용없습니다** — 집의 다른 모든 규칙은 "그녀가 듣는가"인데
  이것 하나만 **보고 있습니다.** 조용한 것이 곧 안전한 것은 아니라는 뜻입니다.
  다락과 홀 난간 위, 둘 다 원래는 공짜였던 길입니다.
- **금고** — 기획서가 처음부터 적어 둔 마지막 원작 요소입니다. 서랍장과 **같은
  컴포넌트**로 만들었습니다. 따로 만들면 배치 테이블이 모르는 통이 되고,
  배치 테이블이 모르는 통은 **아무것도 안 들어 있는 통**입니다.
  → 쪽지를 찾아 → 금고로 가져가 → 안에 든 것을 문으로 가져갑니다. **세 번의 이동.**
  배치 테이블은 **자기를 여는 물건을 자기 안에 넣지 않습니다** (그 배치는
  마지막 서랍까지 열어봐야 못 깨는 걸 알게 됩니다).
- **무기 사물함** — 거실 구석, 유리문에 널빤지를 박아 놓은 총기 캐비닛.
  **새 아이템이 없습니다**: 현관문 널빤지를 떼는 그 망치가 이것도 엽니다.
  한 손뿐이라 **망치를 어디로 먼저 가져갈지가 선택이 됩니다.**
- **잠긴 통이 둘이 되는 순간** 새 교착이 생깁니다 — 망치가 금고 안에, 금고 쪽지가
  사물함 안에. 각각은 "자기를 여는 걸 자기가 안 갖고 있다"를 통과합니다.
  → **뭔가를 여는 물건은 잠긴 통 어디에도 안 들어갑니다.**

## 5. 작업하며 배운 것 (반복하지 말 것)

1. **빌더가 만든 루트는 전부 정리 목록에 있어야 합니다.** 빠지면 리빌드마다 사본이 쌓입니다.
   (워크벤치 / 현관문 / 트럭에서 세 번) → `TheHouseIsBuiltOnceNotTwice` 테스트가 지킵니다.
2. **이름 충돌.** 트럭 짐칸을 `Bed`로 지었더니 침대를 찾던 코드가 트럭을 집어 왔습니다.
3. **통로 폭은 에이전트 반경만큼 깎입니다.** 1 m 틈은 0.4 m가 되어 막힙니다. 최소 2 m.
   (반대로, 난간 간격 0.22 m는 **공짜로 막힙니다.**)
4. **테스트가 "층"으로 판정하면 안 됩니다** — 그녀는 순찰로도 층을 옮깁니다.
5. **`-batchmode`에서는 `WaitForEndOfFrame`이 영원히 안 옵니다.** 캡처는 URP 렌더 리퀘스트로.
6. **공유 `InputActionAsset`은 플레이어마다 복사해야 합니다.**
7. **외형은 테스트로 지킬 수 없습니다.** 찍어서 눈으로 봐야 합니다.
   그리고 **게임의 조명으로** 봐야 합니다 — 조명을 들고 가면 거짓말을 봅니다.
8. **받은 모델을 그대로 쓰면 안 됩니다.** 대낮 사진으로 칠해져 있어서, 어두운 집에서
   혼자 번쩍입니다. `ModelSkin`이 재질을 다시 만듭니다 — **재질별로**. 한 덩어리로
   합치면 옷장 문짝 두 짝이 합판처럼 나옵니다.
9. **회전한 물건의 충돌 상자는 회전 전 치수입니다.** 상자가 홀더에 붙어 있고 홀더가
   돌아가므로, yaw에 맞춰 x/z를 바꾸면 소파 정면이 0.66 m가 됩니다.
10. **모델은 받기 전에 치수를 봅니다.** Poly Haven 색인에 mm 단위로 들어 있습니다.
    `get-model.py --list`가 먼저 보여줍니다.

## 7. 쓰지 않은 것

요청받았던 **디컴파일 저장소는 열지 않았습니다.** 상용 게임을 역컴파일한 코드를 참고하면
이 프로젝트가 원작 코드의 파생물이 되기 때문입니다. 게임 규칙은 저작권 대상이 아니므로
공개 자료를 바탕으로 전부 새로 구현했습니다. 원작의 이름·캐릭터 디자인·대사·음성·모델·로고도
사용하지 않습니다.
