# 아가타의 집 — 작업 요약

> 원작 *Granny*(DVloper, 2017)의 **규칙**을 그대로 옮기고, 캐릭터·이야기·집·아트는
> 전부 새로 만든 1인칭 생존 호러. Unity 6000.5.8f1 / URP.
>
> 이 문서는 작업이 끊겼을 때 **여기부터 다시 읽으면 되는** 지점입니다.
> 마지막 갱신: R6 진행 중 (모드까지 완료, 에셋 다운로드 보류).

---

## 1. 지금 상태 한 줄

플레이 가능한 Windows 실행 파일이 있고, 원작의 핵심 규칙이 전부 들어가 있으며,
집은 기획서 평면도대로 서 있고, 아트만 아직 코드로 생성한 임시 수준입니다.

**테스트: EditMode 80/80 · PlayMode 117/120 통과, 실패 0** (3개는 그래픽이 필요한 캡처 시나리오라 기본 스킵)

---

## 2. 실행 방법

| 무엇 | 어떻게 |
|---|---|
| 게임 하기 | 바탕화면 **`아가타의 집`** 바로가기, 또는 `Build/AgatasHouse/AgatasHouse.exe` |
| 전체 다시 짓기 | `./tools/unity.ps1 run -Method Granny.EditorTools.RebuildAll.Run` |
| 테스트 | `./tools/unity.ps1 test -Platform EditMode` / `-Platform PlayMode` |
| 실행 파일 굽기 | `./tools/unity.ps1 run -Method Granny.EditorTools.GameBuilder.BuildWindows` |
| 집 진단 | `./tools/unity.ps1 run -Method Granny.EditorTools.HouseDoctor.Run` |
| 아가타 사진 | `./tools/unity.ps1 run -Method Granny.EditorTools.AgataPortrait.Run -WithGraphics` |
| 플레이 녹화 | `./tools/unity.ps1 test -Platform PlayMode -WithGraphics -Extra @('-runScenario','-testFilter','HearingScenarioCapture')` |

**빌더 실행 순서는 `RebuildAll` 하나에 고정되어 있습니다.** 순서를 직접 바꿔 돌리면
`HouseBuilder`가 지우고 다시 만드는 마커를 `GrannyBuilder`가 가리키게 되어 null이 생깁니다.

## 3. 끝난 것

### R1 — 고치기 ("쫓아온다")
- **청취 규칙**: `NoiseBus`가 좌표 + 층을 담아 **집 전체로** 발행. 반경 판정 폐기.
  `NoiseRules`가 들릴 소리만 통과 — 깨짐 · 물건 충격 · 문 세게 닫기 · 도구질 · 덫 · 삐걱임 · 종.
  **걷기 · 문 여닫기 · 서랍은 통과하지 않습니다.**
- **한 손 원칙**: 벨트 5칸 제거, 손 하나만. (벨트 코드는 `backup/belt-inventory` 브랜치)
- 문이 90° 돌아가던 버그: 프리팹 루트를 개구부 중심으로, 문은 **벽이 보고한 개구부 목록**에서만 생성
- 옷장이 계단 막던 문제, 벽 z-fighting, 계단 옆 1 m 구덩이, NavMesh 에이전트 반경(0.5 → 0.3)
- **조명은 라이트맵 베이크 오류가 아니었음** — 베이크된 조명이 아예 없었고, 주변광·안개·알베도·
  Forward 광원 제한 네 가지가 겹친 것. Forward+로 전환
- 검증: 지하 스폰 → 2층 병 깨짐 → **실제로 29초 만에 도착**하는 3카메라 녹화 (`docs/verification/r1`)

### R2 — 원작 규칙
| 단계 | 내용 |
|---|---|
| R2-1 | 삐걱이는 바닥(웅크리면 조용), 인계철선 종(하루 한 번) |
| R2-2 | 수색 실패 → **병목에 곰덫 설치**(최대 3개, 오래된 것부터 제거), 밟으면 20초간 속도 60% |
| R2-3 | **숨는 걸 봤는가** 규칙 — 봤으면 그 옷장을 정확히 열러 옴. 침대 밑 숨기 |
| R2-4 | 석궁 조립(부품 3개, 작업대), 다트는 손을 차지하지 않음, 기절 120/60/30/15초, **먼 곳 부활** |
| R2-5 | 소리 15종을 **코드로 합성**(다운로드 없음), 3D 오디오, 지팡이 소리로 위치 추적 |
| R2-6 | 날짜별 부상(시야 흔들림·핏자국, **속도는 안 깎음**), 점프스케어 |

### R3 — 집 다시 짓기
- 기획서 평면도: 중앙 홀 + 네 모서리 방, 2층도 같은 벽선 위에 (방이 방 위에)
- **트인 현관 홀** — 2층 바닥에 구멍 + 사방 난간. 난간에서 현관문이 보이고 홀에서도 난간이 보임
- 계단 분리: 지하 계단은 응접실, 2층 계단은 계단홀
- **차고 + 기어가는 통로** — 천장 1.2 m. 그녀는 NavMesh 기준 1.9 m라 **걸을 면 자체가 생성되지 않음**.
  플래그가 아니라 물리적 사실. 웅크린 플레이어는 1.05 m라 통과

### R4 — 탈출과 퍼즐
- **배치 5종** (무작위 아님) — 익힐 수 있게. 선택된 배치는 세이브에 기록 (안 그러면 이어하기 때 도구가 이동)
- **현관문 6단계**, 난이도가 떼어냄: 3 / 3 / 4 / 5 / 6
- **트럭 탈출** (차고) — 사슬·플러그·배터리·연료·열쇠 5개, 난이도 무관
- 기획서가 이름으로 요구한 테스트: **다섯 배치 전부 클리어 가능**. 별도 목록 없이 씬의 탈출로에게 직접 질의

### R5/R6 — 일부
- **아가타가 캡슐에서 관절 있는 인물로.** 코드로 생성한 뼈대 + 박스/구.
  굽은 등, 긴 팔, **발광하는 뿌연 눈**(어두운 집에서 유일하게 읽히는 것), 비대칭, 쇠끝 지팡이
- `AgataPose` — 애니메이션 클립 없이 **에이전트의 실제 속도**에서 걸음을 계산 (발이 미끄러지지 않음)
- 숨어 있을 때 **심장 소리** (그녀가 가까울수록 커지고 빨라짐)
- **어두운 모드** (R1 이전의 어둠을 모드로), **추가 잠금 모드**

## 5. 작업하며 배운 것 (반복하지 말 것)

1. **빌더가 만든 루트는 전부 정리 목록에 있어야 합니다.** 빠지면 리빌드마다 사본이 쌓이고,
   옛 사본이 계단을 막아 "AI가 고장난 것처럼" 보입니다. (워크벤치 / 현관문 / 트럭에서 세 번)
   → `TheHouseIsBuiltOnceNotTwice` 테스트가 지킵니다.
2. **이름 충돌.** 트럭 짐칸을 `Bed`로 지었더니 침대를 찾던 코드가 트럭을 집어 왔습니다.
3. **통로 폭은 에이전트 반경만큼 깎입니다.** 1 m 틈은 0.4 m가 되어 막힙니다. 최소 2 m.
4. **테스트가 "층"으로 판정하면 안 됩니다** — 그녀는 순찰로도 층을 옮깁니다. 상태로 판정할 것.
5. **`-batchmode`에서는 `WaitForEndOfFrame`이 영원히 안 옵니다.** 캡처는 URP 렌더 리퀘스트로.
6. **공유 `InputActionAsset`은 플레이어마다 복사해야 합니다.** 안 그러면 테스트 간 오염.
7. **외형은 테스트로 지킬 수 없습니다.** `AgataPortrait`로 찍어서 눈으로 봐야 합니다.

## 7. 쓰지 않은 것

요청받았던 **디컴파일 저장소는 열지 않았습니다.** 상용 게임을 역컴파일한 코드를 참고하면
이 프로젝트가 원작 코드의 파생물이 되기 때문입니다. 게임 규칙은 저작권 대상이 아니므로
공개 자료를 바탕으로 전부 새로 구현했습니다. 원작의 이름·캐릭터 디자인·대사·음성·모델·로고도
사용하지 않았습니다.
